## 必要な機能 
- 地点を3つ以上から選べる（例：東京は緯度 35.68、経度 139.77。ほかの地点の緯度と経度は地図サービスで調べてコードに書く） 
- 選んだ地点の、現在の気温と天気 
- 今日と明日の、最高気温
- 最低気温
- 降水確率 
- 天気コード（数字）を、次の表のとおり日本語にして表示する（コードの意味は https://open-meteo.com/en/docs の「WMO Weather interpretation codes」の表にある） 　
- 晴れ：0、1 　
- くもり：2、3 　
- 霧：45、48 　
- 雨：51、53、55、56、57、61、63、65、66、67、80、81、82 　
- 雪：71、73、75、77、85、86 　
- 雷雨：95、96、99 　
- 上の表にない数字：不明 
- データを取っている間は「読み込み中」と分かる表示を出す 
- データを取れなかったときは、そのことを伝える文と「もう一度」ボタンを出す 
- 画面に出典として「Weather data by Open-Meteo.com」を、https://open-meteo.com/ へのリンクで表示する

## データの取り方の例（東京） 
https://api.open-meteo.com/v1/forecast?latitude=35.68&longitude=139.77&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=Asia%2FTokyo&forecast_days=2 
- timezone=Asia%2FTokyo を付けると、「今日」「明日」が日本の日付になる 
- このURLをブラウザで開くと、返ってくるデータの形を確かめられる

## できたと言える状態 
- 地点を切り替えると、その地点の気温と天気に変わる 
- 画面の気温
- 最高気温
- 最低気温
- 降水確率が、同じ地点のデータの取り方の例のURLをブラウザで開いたときの値と一致する 
- 天気が数字ではなく、表のとおりの日本語で表示されている（表にない数字のときは「不明」になるよう、コードの対応を書いた部分を読んで確かめる） 
- ブラウザの開発者ツールで通信を遅くすると（Network の Slow 4G など）、読み込み中の表示が見える 
- ページを開いた後で開発者ツールの通信をオフラインにし、地点を切り替えると、取れなかったことを伝える表示が出る 
- 通信を戻して「もう一度」を押すと、天気が表示される 
- 出典のリンクが表示されている

## 利用条件 
- Open-Meteo は、広告や有料会員制のない個人の作品であれば無料で使える 
- データを取りに行く回数は1日1万回未満にする（ページを開いたり地点を切り替えたりするたびに1回と数える。自分で確かめる程度なら気にしなくてよい）
